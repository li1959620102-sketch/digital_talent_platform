# DESIGN.md · AI数字化人才平台 面试答辩 PPT

> 命中分支：**商务咨询风（consulting）**——权威、数据密集、结构化分析。场景为项目评审/方案答辩/验收考核，明确属于咨询/评审专业领域。结构层 + 常量值层共同构成本项目设计宪法。

## 1. 画布与全局母版

- 画布：1280 × 720（16:9）。
- 页面左右 padding：60px。

### 母版四区（咨询风）

| 区域 | 位置 | 规则 |
|---|---|---|
| A 页眉 | y 0–44 | 右上角 14px 灰字章节进度（如"02 · 总体设计"），禁彩色竖条 |
| B 标题块 | y 44 起，自适应 | Action Title 32–36px Bold，左对齐；顶部紧贴 y=44；单行高约 60px；底部 1px 黑线紧随标题下 8–12px 作分割 |
| C 内容区 | 分割线下 12px 起 至 y 660 | 正文/图表/结构图/卡片；上沿跟随 B 区实际底线 |
| D 页脚 | y 660–700 | 左：Source/Footnote 14px 灰；右：页码 NN 14px 灰 |

省略规则：封面、章节扉页、结束页省略 A/D；目录保留右下页码；正文/图表/结构图页完整遵守。

## 2. 色彩系统（≤4 hex + 中性灰）

| 角色 | hex | 用途 |
|---|---|---|
| Navy 主色 | `#061F32` | 章节底、主框架、重点色块 |
| 皇家蓝 | `#001965` | 图表第二档、层级色 |
| Cyan 强调 | `#08A6F6` | 关键点缀、数据标注，单页 ≤5% |
| 浅蓝 | `#99BDED` | 图表第三档、辅助色阶 |
| 中性灰 | `#E7E6E6` / `#808080` / `#44546A` | 表底、脚注、边框、正文 |
| 背景 | `#FFFFFF` | 内页主底 |

- **主色占比 ≤60%**（章节底、封面底）；**辅色 ≤30%**（卡片底）；**强调色 ≤8%**（Hero 页可到 15%）；中性灰其余。
- 禁：金色、中国正红、朱砂、紫粉黄、彩虹、阴影发光、3D。
- 涨跌色：本 PPT 无涨跌图表，不使用暗红/绿。

### 渐变与半透明
- 封面/章节扉页：`linear-gradient(135deg, #061F32 0%, #0A2E4A 100%)`。
- 卡片浅底：`rgba(6,31,50,0.04)` 大面积浅灰蓝。
- 强调数字可用 Cyan 纯色，不用渐变文字。

## 3. 字体系统

字体家族：`Arial, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`。

| 层级 | px | 字重 | 用途 |
|---|---|---|---|
| 章节编号巨字 | 180–260 | Bold | 仅章节扉页 |
| 封面主标 | 64–76 | Bold | 封面 |
| KPI 大数 | 72–96 | Bold | 数据页锚点 |
| Action Title | 32–36 | Bold | B 区固定 |
| 副标/卡片小标 | 24–28 | Bold | 次级标题 |
| 正文 | 22–24 | Regular | 段落（硬下限 ≥22px） |
| 数据标签 | 16–18 | Regular | 图表标签 |
| Source/Footnote/页码 | 14 | Regular | 页脚 |

单页字号种类 ≤5；正文 ≥22px；相邻层级拉开 ≥6px。

## 4. 信息密度与可读性

| 类型 | 下限 |
|---|---|
| 封面 | 主标+副标+时间 ≥20 字 |
| 目录 | 5 条，每条编号+章节名+摘要，总 ≥80 字 |
| 章节扉页 | 巨字编号+章节标题+英文副标 ≥14 字 |
| 单主题 | 正文+主视觉 ≥120 字，图 ≥30% |
| 卡片组 | 每卡 ≥40 字，合计 ≥120 |
| 数据图表 | 主图 ≥50%，洞察 50–90 字 |

- 可读性：对比度 ≥4.5:1；浅灰底黑字/Navy 字；Cyan 底禁白字；卡片填充率 ≥75%；正文行高 1.4–1.5。
- 留白 25–40%；内容必须承担判断/论据/结论，极简≠空。

## 5. 配图与视觉元素

| 等级 | 用途 | 规则 |
|---|---|---|
| L1 主视觉 | 架构图/Agent中枢图 | C 区 ≥40%，走 SVG 结构图 |
| L2 支撑图/icon | 卡片头、流程节点 | icon 24–48px 线性单色 Navy/Cyan |
| L3 母版徽标 | 统一角标 | 仅 D 区左下 logo 位 |

- L1 视觉类型：**数据可视化/结构图类**（架构图、Agent中枢图用 SVG，文字独立文本层，不烤进 SVG）。
- 封面主视觉用 SVG 抽象科技几何（渐变网格+节点连线），不用具象照片。
- icon 仅线性单色，禁 emoji、彩色填充、渐变。
