# STORY.md · AI数字化人才平台 面试答辩 PPT

## ① 用户意图对齐

- **目标受众**：项目评审专家、验收考核评委、方案答辩评审团（甲方技术/业务负责人、信息化专家）。
- **核心目标**：听完后评委相信——① 平台在 7 天内完成了全部 P0+P1 功能且经实测验证；② 技术架构先进且落地扎实（LangGraph 五大 Agent + Dify + Milvus 四库混合存储）；③ 关键指标有真实数据支撑（78 测试全绿、简历解析 100%、匹配精度 Golden 100%、延迟 18s→5s）；④ 对剩余 P2 项有清晰的边界与规划，体现工程诚信。最终动作：签字验收 / 评审通过。
- **PPT 长度**：共 20 页（对应 15–20 分钟现场汇报，每页约 1 分钟）。
- **视觉调性**：权威克制 / 数据驱动 / 结构清晰 / 工程可信（商务咨询风：Navy 权威感 + 数据图表 + Action Title）。
- **内容边界**：
  - **必讲**：项目背景与建设目标、总体架构（六层四库）、五大 Agent 与 AI 智能层、P0 功能全景、测试与性能实测数据、安全合规与国产化、验收交付物、P2 边界与后续规划。
  - **不讲**：内部实现细节（如某个 SQLAlchemy 枚举 Bug 的代码细节）、敏感凭据（API Key/Token）、商务报价细节。
  - **禁碰**：不得声称未实测项已达标（arm64、2000 并发、移动端真机须标"待验证"）；不得暴露任何 API Key、数据库密码。
