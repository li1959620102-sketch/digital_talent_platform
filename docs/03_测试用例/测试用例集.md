## 一、测试策略

### 1.1 测试层次

| 层次 | 范围 | 环境 | 工具 | 用例数 |
|---|---|---|---|---|
| 单元测试 | Service 层纯函数、工具类、算法、RBAC 与配置基线 | 内存 SQLite（`sqlite:///:memory:` + `StaticPool`） | pytest | 69 |
| 集成测试 | API 端到端（TestClient）、跨模块业务闭环 | TestClient + 内存 SQLite | pytest + FastAPI TestClient | 28 |
| 联调验证 | 真实 MySQL/Milvus/Redis/Ollama/Dify | 真实服务栈（docker-compose.dev + 本地） | 自研脚本 | 3 个脚本 |
| 性能测试 | 接口压测、并发突发 | 真实 MySQL | locust + 自研脚本 | — |
| 安全测试 | 认证/授权/注入/审计 | 单测 + live | 手工 + 单测（**10-14 起含 13 条自动化**） | — |
| 兼容性测试 | 浏览器/OS/分辨率/移动端 | 手工 | — | — |

### 1.2 用例编号规则

`TC-<模块代码>-<三位序号>`，模块代码：

| 代码 | 模块 | 代码 | 模块 |
|---|---|---|---|
| AUTH | 认证与权限 | KB | 知识库 RAG |
| TALENT | 人才档案 | AGT | AI 智能体 |

| DASH | 数据看板 | PERF | 性能 |

### 1.3 用例设计方法

| 方法 | 应用场景 |
|---|---|
| 等价类划分 | 字段取值域（学历、状态、题型枚举） |
| **边界值分析** | 分页参数、经验年限、匹配阈值、上传大小、难度等级 |
| 判定表 | 权限组合（角色 × 操作 × 数据范围） |
| 错误推测 | 空值、超长、非法枚举、并发冲突 |
| 场景法 | 业务闭环（建档→测评→匹配→培训→考核） |

### 1.4 优先级定义

- **P0**：阻塞验收，必须通过
- **P1**：重要功能，不影响主链路验收
- **P2**：增强能力，可迭代
