# KB01 - AI数字化人才平台：核心架构与部署指南

## 一、平台整体架构

AI数字化人才平台是一个企业级的 AI 原生人才智能分析平台，采用前后端分离的云原生架构，由以下七层组成：

```
┌───────────────────────────────────────────────────────────┐
│                 前端展示层 (React 18 + Vite)              │
│  Dashboard · 人才档案 · 岗位管理 · 测评 · 培训 · 匹配     │
├───────────────────────────────────────────────────────────┤
│                 Nginx 反向代理层 (端口 8080)              │
│    / → 前端 dist 静态资源   /api/v1 → 后端 :8003          │
├───────────────────────────────────────────────────────────┤
│               后端 API 服务层 (FastAPI · Python 3.11)     │
│       9 大路由模块 · 5 大 AI Agent · Dify Workflow 集成   │
├───────────────────────────────────────────────────────────┤
│              服务与 AI 推理层                             │
│  Ollama(qwen3/bge-m3) · Milvus 向量库 · Redis 缓存       │
│  MinIO 对象存储 · Vanna NL2SQL · LLM 策略路由             │
├───────────────────────────────────────────────────────────┤
│              数据持久层                                   │
│  MySQL (业务主库) · PostgreSQL (分析库)                   │
├───────────────────────────────────────────────────────────┤
│              监控与日志                                   │
│  Python logging · RotatingFile · 慢 SQL 审计              │
└───────────────────────────────────────────────────────────┘
```

## 三、部署顺序（首次上线必看）

1. **基础设施**：按顺序启动 MySQL、PostgreSQL、Redis、MinIO、Milvus、Ollama
2. **数据库初始化**：
   ```bash
   # alembic 建表 + seed 数据
   alembic upgrade head
   conda run -n ai_py311 python -m app.core.seed
   ```
3. **后端启动**：
   ```bash
   cd backend
   conda run -n ai_py311 uvicorn main:app --host 0.0.0.0 --port 8003
   ```
4. **前端构建与部署**：
   ```bash
   cd frontend
   npm install
   npm run build  # 产物在 frontend/dist
   # 复制 dist 到 Nginx html 目录
   ```
5. **Nginx 配置**：静态资源指向 dist，`/api/v1` 反向代理到 `http://127.0.0.1:8003/api/v1`

## 五、常见排错

### 5.1 前端访问返回缓存旧版
Nginx 静态资源加 `Cache-Control: no-cache` 响应头，或 Ctrl+Shift+R 强制刷新。

### 5.2 后端启动报 Milvus 连接失败
Milvus 启动较慢，后端采用懒加载，首次调用向量接口才会实际连接，属正常现象。

### 5.3 接口 401 Unauthorized
检查 JWT 配置：`.env` 的 `SECRET_KEY` 不能为空，后端 `ACCESS_TOKEN_EXPIRE_MINUTES` 默认 30 分钟。

### 5.4 岗位匹配接口报 500
检查 `job_positions.skill_requirements` 列是否为合法 JSON 数组，不允许 Python 字面量字符串（单引号格式）。
