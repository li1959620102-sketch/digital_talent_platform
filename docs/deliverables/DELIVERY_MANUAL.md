# AI数字化人才平台 — 交付手册（操作 + 运维 + 视频教程）

> 配套 `ACCEPTANCE_PACKAGE.md`（验收材料包）。所有账号默认：管理员 admin / admin123。

---

## 一、操作手册（普通用户）

1. **人才档案**
   - 人才列表：查看/搜索/筛选（学历、状态、部门）；新增（手动表单或 Excel 批量导入）。
   - 简历解析：上传 Word/PDF/图片简历 → 系统自动解析字段、生成标签与人才画像。
   - 查重：保存时按手机号/邮箱自动查重，重复数据拦截并提示。

2. **AI智能测评**
   - 题库：管理员维护题目（单选/多选/判断/填空/简答/论述）。
   - 组卷：按岗位/层级自定义试卷，设定时长与能力维度。
   - 测评：发起批量/定向/自主报名测评；提交后自动评分并生成能力雷达图。

3. **岗位匹配**
   - 创建岗位（任职要求/技能/学历/经验）。
   - 一键匹配：对岗位匹配候选人才，输出匹配度 0–100 分与匹配依据（学历/经验/技能重叠）。

4. **培训赋能**
   - 课程库：图文/视频/文档课程，按岗位/技能/层级分类。
   - 学习计划：系统按能力缺口推荐个性化课程。
   - 在线学习：进度/学时自动记录；课后考核随机出题自动阅卷。

5. **数据看板**
   - 驾驶舱：人才总量/结构/技能分布/测评合格率/培训完成率。
   - 智能预警：人才缺口/技能短板/培训滞后/岗位适配不足。

## 二、操作手册（管理员）

- **权限管理**：超级管理员/部门管理员/审核/普通员工/访客；自定义角色与数据权限（行级+字段级）。
- **组织与用户**：部门维护、账号批量管理、手机验证码登录、异常登录预警与账号锁定。
- **知识库**：上传制度/课件/岗位说明书 → 自动切片向量化 → RAG 问答（带权限过滤与来源追溯）。
- **系统配置**：模型路由（Ollama/硅基流动）、Milvus/Redis 连接、Dify 中台接入。

## 三、运维手册

### 3.1 部署（Docker Compose，单机）
```bash
cd docker
docker compose -f docker-compose.dev.yml up -d   # 核心：MySQL/PostgreSQL/Redis
docker compose up -d                             # 全栈：+ Milvus/Ollama/Nginx/Backend
```
- 后端：`uvicorn main:app --host 0.0.0.0 --port 8003 --workers 4`
- 前端：`cd frontend && npm install && npm run build`（产物 `dist/` 由 Nginx 托管）
- API 文档：`http://<host>:8003/api/v1/docs`

### 3.2 数据库
- 业务主数据：MySQL（users/permissions/organizations/业务表，**21 张**）
- 分析宽表：PostgreSQL（履历/测评/培训/时序）
- 向量：Milvus（talent_resume / job_position / knowledge_base 三集合）
- 缓存/会话/Agent记忆：Redis
- **备份**：MySQL `mysqldump`、PgSQL `pg_dump`、Milvus 快照、Redis AOF；建议每日定时 + 异地备份。

### 3.3 监控与巡检
- 健康检查：`GET /health`
- 日志：`backend/logs/`（请求日志含用户/时间/IP/操作；AI 调用含模型/Prompt版本/Token/耗时）
- 巡检：每月一次（见售后 SLA），检查服务存活、磁盘、备份完整性、审计日志完整性。

### 3.4 常见故障
| 现象 | 排查 | 处理 |
|---|---|---|
| 登录慢 | 同机 Ollama/Milvus 占满 CPU | AI 推理层与 API 层分离部署（K8s 资源隔离） |
| 向量检索慢 | Ollama embedding 网络 | 生产 GPU embedding；检查 Milvus 连接 |
| RAG 无结果 | 知识库未向量化 | 重新 vectorize；检查 Milvus 集合 |
| 启动报集合不存在 | EMBEDDING_DIM 未配置 | 在 .env/config 设置 EMBEDDING_DIM=1024 后重启 |

### 3.5 国产化（方案 A）
- 数据库/中间件保持开源兼容（MySQL/PostgreSQL/Redis/Milvus），无需替换。
- 构建 arm64 镜像以适配国产 CPU（鲲鹏/飞腾）+ OS（麒麟/统信）：
  ```powershell
  .\docker\build_arm64.ps1     # docker buildx --platform linux/arm64
  ```

## 四、操作教程脚本

1. **登录与权限**：浏览器打开前端 → 输入 admin/admin123 → 登录成功 toast。
2. **人才驾驶舱**：进入"人才数据驾驶舱" → 展示人才总量/岗位数/学历结构/预警。
3. **人才管理**：人才列表（真实分页）→ 新增人才（填写表单）→ 列表刷新出现新记录 → 删除。
4. **岗位管理**：岗位列表 → 新增岗位（任职要求/技能）→ 列表出现新岗位。
5. **岗位匹配**：对岗位触发匹配 → 候选人才按匹配度排序，展示匹配依据。
6. **知识库问答**：上传制度文档 → 向量化 → 提问 → 返回基于知识库的回答与来源。
7. **AI Agent**：演示测评分析/培训推荐/数据决策 Agent 返回结构化结果。
