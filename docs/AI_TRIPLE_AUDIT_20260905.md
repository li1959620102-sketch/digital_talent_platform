## 二、发现的体验问题（按严重度排序）

### 🔴 P0 严重误导（甲方演示会被当场质疑）

#### 1. 知识库问答"答非所问"却列出多个来源 → AI 乱答嫌疑
**实测**：HR 问"请休假几天？"，系统答"知识库未包含请休假天数相关信息"，但下面列了 4 个"来源：policy.txt × 4"。
**原因**：后端 `app/services/knowledge_service.py:qa` 在 `contexts` 非空时**无条件**返回 sources，LLM 答"未包含"时仍展示来源。
**影响**：甲方看到"未包含"+ "来源文件"会立刻认为"这 AI 乱报来源可信度"。
**已修**（前端 KnowledgeBase.tsx）：来源区仅当答案非"未检索到/未包含/无法回答"等兜底文案时才展示。

#### 2. 知识库问答页有"原始结果"JSON 调试卡
**实测**：提问后页面同时显示"回答"卡 + 一个超大的"原始结果"卡（`JSON.stringify(answer, null, 2)` 格式化输出）。
**原因**：KnowledgeBase.tsx 同时渲染了友好答案 + 原始 JSON 调试卡。
**影响**：甲方看到这种"开发者调试输出"会觉得产品未完成。
**已修**：删除"原始结果"卡。

#### 3. 数据参谋问数结果暴露 SQL 源码
**实测**：admin 问"统计本科及以上学历的人才数量"，结果卡片第一行直接展示 `SQL` 标签 + 一行 `SELECT ... LIKE '%本科%' ...` SQL 语句 + 原始 rows 表。
**原因**：AgentCenter.tsx AskPanel 直接渲染后端返回的 `result.data.sql`。
**影响**：业务用户问"本科人才多少"根本不关心 SQL。这是开发者工具，不是产品结果。
**已修**：SQL 折叠在 `<details>` 里，默认隐藏"查看执行的 SQL"，让结果区只显示自然语言建议 + 表格。

### 🟠 P1 明显体验问题

#### 4. 技能编排组件类别显示技术英文（`ai/data/notify/security`）
**实测**：截图确认——每个组件名字后面紧跟 `ai`、`data`、`notify`、`security` 技术英文标签。
**原因**：SkillsDesigner.tsx 直接显示 `c.category` 字段（技术英文），无中文映射。
**已修**：新增 `CATEGORY_LABELS = {ai: '智能能力', data: '数据能力', notify: '通知', security: '安全'}`。

#### 5. 技能编排"触发机制"显示两次"手动触发"
**实测**：中间面板"触发机制：[手动触发 Select] 手动触发[Text]"——同一文案出现两次。
**原因**：Select 自身显示当前值，右侧又渲染 `<Text>{TRIGGER_LABELS[draft.trigger_type]}</Text>`。
**已修**：删除重复 Text。

#### 6. 技能编排"保存/执行"按钮在空编排时仍可点
**实测**：新建空白编排，两个按钮都可点。点了会弹"请先保存编排"或无效请求。
**影响**：明显不该可点的无效按钮。
**已修**：`disabled={draft.steps.length === 0}` 同时禁保存和执行按钮。

#### 7. 普通员工知识库首屏大量空白，无引导
**实测**：wangwu 登录后点"智能知识库"，页面只有 1 个输入框 + placeholder，下方 60% 空白（截图 D:/wangwu_kb.png）。
**原因**：普通员工不熟悉业务，问"该问什么"没方向。
**已修**：加 6 个建议问题 Tag（培训课程/上传简历/测评解读/AI 能力/请假/岗位匹配），点击自动填充并触发提问。

### 🟡 P2 细节打磨

#### 8. ModuleBanner 对所有角色显示相同的上下游跳转链接
**实测**：HR/普通员工进入知识库，看到横幅"→ 人才档案"，但他们没有人才档案权限。
**影响**：点了会被 RequireStaff 重定向回首页，造成困惑。
**建议**：ModuleBanner 应根据当前用户角色过滤跳转链接（admin/hr 才显示"→ 人才档案"；user 隐藏或改为"→ 我的成长"）。

#### 9. 数据参谋问数响应慢（实际 LLM 生成 SQL 慢）
**实测**：单次问数在测试中 90s 仍未返回。LLM 生成 + Milvus 检索 + PgSQL 执行全链路。
**影响**：演示时甲方可能等 1~2 分钟，体感很差。
**建议**：增加 loading 提示文本生成进度（"检索中...正在生成 SQL..."），设置 60s 客户端超时降级，或在文档里明确"NL2SQL 平均 30~60 秒"。

#### 10. 知识库文件列表"权限级别"显示原始数字（`0`）
**实测**：表格列"权限级别"显示 `0`，用户不知 0 是什么。
**建议**：把 `0/1/2/3` 映射为"全员可见/登录可见/指定角色/超管"等中文标签。

#### 11. 技能编排无编排时整个右半部分空白
**实测**：空编排状态下，"步骤参数"和"执行结果"区域只有空态插画，没有引导"先把组件从左边拖入流程"。
**建议**：空态加引导文案 + 一键试用模板（如"自动盘点未测评人才"模板）。
