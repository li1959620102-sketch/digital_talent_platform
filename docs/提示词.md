- 数据迁移要求

业务CRUD：

> 使用SQLAlchemy ORM。

NL2SQL：

> 只允许访问只读数据库 / 只读Schema。

执行流程：

```text
自然语言
↓
SQL生成
↓
SQL AST解析
↓
SQL安全检查
↓
表白名单
↓
字段白名单
↓
用户权限
↓
LIMIT
↓
超时控制
↓
只读执行
```

禁止：

```text
DROP
DELETE
UPDATE
INSERT
ALTER
TRUNCATE
CREATE
GRANT
REVOKE
EXEC
```

不得仅依赖字符串正则作为唯一安全措施。
