> 阶段：第二阶段（设计文档）
> 版本：v1.0 ｜ 编制日期：2026-09-16
> 接口总数：**107 个**（`/api/v1` 前缀下）+ 2 个根级接口
> 在线文档：`http://<host>:8003/api/v1/docs`（Swagger UI）｜ `http://<host>:8003/api/v1/redoc`

## 一、通用约定

### 1.1 基础信息

| 项 | 值 |
|---|---|
| 协议 | HTTP / HTTPS |
| 默认端口 | 8003（`backend/.env` 的 `PORT`）；容器内为 8000 |
| API 前缀 | `/api/v1` |
| 数据格式 | JSON（文件上传为 `multipart/form-data`） |
| 字符集 | UTF-8 |
| 时间格式 | `YYYY-MM-DD HH:MM:SS`（本地时区，`Asia/Shanghai`） |

### 1.2 统一响应格式（`app/schemas/common.py` → `ResponseModel`）

**成功响应**：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": { }
}
```

**分页数据**（`data` 内嵌 `PageModel`）：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "total": 194,
    "page": 1,
    "page_size": 10,
    "items": [ ]
  }
}
```

**错误响应**：

```json
{
  "code": 404,
  "message": "人才档案不存在",
  "details": null
}
```

### 1.3 鉴权约定

| 项 | 说明 |
|---|---|
| 认证方式 | JWT Bearer Token |
| 请求头 | `Authorization: Bearer <access_token>` |
| Token 有效期 | access_token 30 分钟；refresh_token 7 天 |
| 携带方式 | 除 `POST /auth/login`、`POST /auth/register` 外，**全部接口均要求认证** |
| 未认证 | 返回 **401** |
| 无权限 | 返回 **403**，`message` 形如 `无权限执行此操作（需要 talent:delete）` |

### 1.4 三层权限模型

| 层 | 机制 | 说明 |
|---|---|---|
| 功能权限 | 权限码 + 4 角色矩阵（33 权限码） | 通过 `Depends(require_permission_or_403(code))` 注入 |
| 字段权限 | 5 类敏感字段脱敏 | 服务端出参前完成，前端拿不到明文 |
| 行级权限 | `data_permissions.data_scope` | 注入查询过滤条件 |

### 1.5 通用请求参数规范

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `page` | int | 1 | 页码，`ge=1` |
| `page_size` | int | 10 或 20 | 每页条数，`ge=1, le=100` |
| `top_n` | int | 10 | TopN 数量，`ge=1, le=50` |
| `top_k` | int | 10 | 检索返回条数，`ge=1, le=50` |
| 批量删除 | body | — | `{"ids": [1,2,3]}` |

### 1.6 脱敏字段可见性矩阵

| 字段 | super_admin | admin | hr | user |
|---|---|---|---|---|
| `phone` | 明文 | 明文 | 明文 | `138****0007` |
| `id_card` | 明文 | 明文 | 打码 | 打码 |
| `email` | 明文 | 明文 | 明文 | `l*******@tencent.com` |
| `address` | 明文 | 明文 | 打码 | 打码 |
| `expected_salary_min/max` | 明文 | 明文 | **置 null** | **置 null** |

## 三、认证模块（`/api/v1/auth`，5 个）

| # | 方法 | 路径 | 说明 | 鉴权 | 权限码 | 请求要点 | 响应要点 |
|---|---|---|---|---|---|---|---|
| 1 | POST | `/api/v1/auth/login` | 用户登录 | **公开** | — | `LoginRequest`：`username`、`password` | `access_token`、`refresh_token`、`token_type`、`user` |
| 2 | POST | `/api/v1/auth/register` | 用户注册 | **公开**（受 `ALLOW_SELF_REGISTER` 控制，默认关闭） | — | `RegisterRequest` | 新建用户信息 |

| 4 | POST | `/api/v1/auth/refresh` | 刷新 Token | 需认证 | — | `refresh_token` | 新 access_token |
| 5 | GET | `/api/v1/auth/me` | 获取当前用户 | 需认证 | — | — | 用户信息 + 角色列表 |

**登录安全设计**：bcrypt（cost=11）校验经 `run_in_threadpool` 卸载；失败累加 `failed_login_count`，达阈值设置 `locked_until`；记录 `last_login_time` / `last_login_ip` / `login_count`。

## 十六、错误码规范

| HTTP 状态码 | 场景 | `message` 示例 |
|---|---|---|
| 200 | 成功 | `操作成功` |
| 400 | 请求参数错误 | `请求参数错误` |
| 401 | 未认证 / Token 失效 | `未认证或登录已过期` |
| 403 | 已认证但无权限 | `无权限执行此操作（需要 talent:delete）` |
| 404 | 资源不存在 | `人才档案不存在` |
| 409 | 资源冲突（唯一约束） | `用户名已存在` |
| 422 | Pydantic 校验失败 | 字段级校验错误 |
| 429 | 请求过于频繁（**网关层**） | — |
| 500 | 服务内部错误 | `服务器内部错误`（**不含堆栈**） |
| 503 | 依赖服务不可用 | `服务暂不可用` |

**异常类映射**（新层 `BaseAPIException` 派生 18 类 + 业务域 6 类，详见《详细设计说明书》第十二章）。
