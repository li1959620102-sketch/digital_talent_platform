# 平台使用手册：AI数字化人才平台快速入门

> 版本：v1.0 · 更新日期：2026-09 · 适用角色：所有用户

## 一、平台概述

**AI数字化人才平台**是一款面向企业人力资源部门的 AI 原生综合应用，融合 **简历智能解析**、**人才素质测评**、**岗位智能匹配**、**培训赋能**、**数据决策** 五大核心能力，通过 AI Agent + RAG 知识库 + 向量数据库 + Dify Workflow 中台的架构，实现人才管理全生命周期的数字化与智能化。

核心模块一览：

| 模块 | 能力说明 | 典型用户 |
|------|---------|---------|
| 数据总表（Dashboard） | 人才池、岗位、学历分布、经验分布、技能分布可视化 | super_admin / admin / hr |
| 人才档案（Talent） | 简历上传、AI 解析、结构化档案、标签管理 | hr / admin |
| 岗位管理（Position） | 岗位新建、状态流转、技能要求、级别与部门关联 | hr / admin |
| 测评管理（Assessment） | 题库、测评计划、AI 分析报告、能力雷达图 | hr / admin |
| 岗位匹配（Matching） | 一岗位匹配 TopN 人才、匹配分、优势/短板、推荐理由 | hr / admin |
| 培训赋能（Training） | 课程、计划、AI 个性化推荐、完成度跟踪 | admin / hr |
| AI 智能体中心（Agent） | 6 类 Agent：简历解析/测评/匹配/培训/决策/KG问答 | admin / super_admin |
| 知识库（Knowledge） | Markdown/Word/Excel 文档入库、RAG 智能问答 | admin / hr |
| 用户管理（User） | 用户、角色、权限、四角色RBAC | super_admin |

## 二、登录与注册

### 2.1 快速登录
1. 访问平台地址：`http://{域名或IP}:8080/`
2. 切换至 **登录** Tab
3. 输入用户名 / 密码
4. 默认超级管理员账号：`admin` / `admin123`

### 2.2 新用户注册
1. 切换至 **注册** Tab
2. 填写：用户名（≥3字符）、密码（≥6位）、真实姓名（选填）、邮箱（选填）、手机号（选填）
3. 点击 **注册并登录**，系统创建用户（默认角色 `user`）并自动登录
4. 需要更高权限请联系超级管理员在「用户管理」页调整角色

### 2.3 角色权限速查

| 角色 | 数据总表 | 人才档案 | 岗位管理 | 测评管理 | 培训/匹配/知识/Agent | 用户管理 |
|------|---------|---------|---------|---------|---------------------|---------|
| super_admin | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| admin       | ✅ | ✅ | ✅ | ✅ | ✅ | ❌ |
| hr          | ✅ | ✅ | ✅ | ✅ | ✅ | ❌ |
| user        | ✅ | 只读 | 只读 | 只读 | 只读 | ❌ |

## 三、典型操作流程

### 3.1 简历入库（HR 最常用）
1. 进入「人才档案」→ 点击 **上传简历**
2. 选择 PDF / Word / Excel 文件（最大 50MB）
3. 系统自动触发 **简历解析 Agent**，提取：姓名、学历、工作年限、技能、项目经历……
4. 解析结果进入人才档案列表，可编辑、标注标签、导出

### 3.2 新建岗位 + 触发匹配
1. 进入「岗位管理」→ **新增岗位**
2. 填写：岗位名称、部门、级别、学历要求、经验要求、**技能要求（可多选+熟练度）**
3. 保存后进入「岗位匹配」，选择该岗位，设置 TopN，点击 **触发匹配**
4. 查看匹配结果表格：人才ID/姓名、匹配分、优势技能、短板技能、推荐理由

### 3.3 发起人才测评
1. 进入「测评管理」→ **新增测评计划**
2. 选择测评维度（技术/性格/通用能力）、题库难度、关联候选人
3. 候选人完成作答后，平台调用 **测评分析 Agent** 生成雷达图 + 文字报告

### 3.4 知识库智能问答
1. 进入「知识库」→ **上传文件**（支持 .md/.txt/.docx/.pdf）
2. 系统自动切片向量化 → 存入 Milvus `knowledge_base` 集合
3. 在问答输入框提问，如：「新员工入职需要准备哪些材料？」
4. RAG 检索 + LLM 生成回答，并在下方列出引用片段与来源文件

## 五、常见问题 FAQ

**Q：登录提示 401？**
A：检查 token 是否过期（默认30分钟），重新登录即可。前端已配置 axios 拦截器自动跳登录页。

**Q：上传 PDF 简历后，解析结果为空？**
A：① 确认 PDF 不是扫描件（OCR 需额外开启）；② 在「AI 智能体中心 → 简历解析 Agent」查看该文件的运行日志；③ 联系管理员检查 LLM 策略（ollama / SiliconFlow）连通性。

**Q：岗位匹配返回 500？**
A：通常是该岗位的 `skill_requirements` 字段格式异常（例如 Python 字面量字符串而非合法 JSON）。请联系管理员在岗位编辑页重新保存技能要求。

**Q：知识库问答找不到答案？**
A：① 确认文件状态为「已向量化」；② 问题请用完整中文句子，避免关键词过短；③ 可在「AI 智能体中心 → RAG」手动调整 top_k / threshold 参数。

**Q：图表/仪表盘显示「加载中」？**
A：首次加载数据需拉取汇总接口（约 1-2 秒）。长期 loading 请按 F12 查看 XHR 是否返回 401/500，按上方 FAQ 对应处理。
